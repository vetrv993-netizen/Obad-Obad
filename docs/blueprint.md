# **App Name**: NutriScan

## Core Features:

- Visual Vision Scanner: Utilizes a generative AI vision tool to instantly identify food items via the camera for nutrition analysis.
- Bilingual UI Dashboard: A sophisticated interface supporting seamless switching between English and Arabic, featuring Right-to-Left (RTL) optimization.
- Biometric Insight Engine: A detailed visualization hub showing breakdown of calories, proteins, fats, and carbohydrates for any identified dish.
- Smart Suggestion Tool: A generative AI health tool that provides personalized nutritional advice and meal suggestions based on scanning history.
- Nocturnal Storage Library: Integrates an offline database to allow for rapid lookup of food data without an active internet connection.
- The Digital Ledger: Persistent storage for favorites and history screens, implemented via a robust Firestore database for cloud synchronization.

## Style Guidelines:

- Primary color: Electric Indigo (#BF89FF), used for data accents and key action highlights.
- Background color: Nocturnal Depth (#141217), providing a deep, premium dark-mode aesthetic that minimizes eye strain.
- Accent color: Glacial Periwinkle (#CCCCFF), chosen to provide high contrast against the dark background for secondary text and UI elements.
- A professional font pairing of 'Space Grotesk' for modern, tech-forward headlines and 'Inter' for high-readability body text in both English and Arabic scripts.
- Sleek, lightweight outlined iconography that feels precise and clinical, reinforcing the scientific nature of nutrition tracking.
- Mobile-optimized vertical scroll with ergonomic touch targets and an emphasis on the central camera scanner button.
- Smooth, high-frame-rate micro-interactions and a pulsing 'holographic' scan effect when the AI vision tool is processing image data.
